# 可扩展静态检查规则引擎（lint-rule-engine-java）

基于 Java 17 的可扩展静态检查引擎：插件化规则、目录级配置继承、行内抑制、
确定性自动修复、增量缓存、并发与取消。核心引擎不依赖 Spring，可独立使用；
同时提供 Spring Boot 自动装配与 REST 接口。

## 快速开始

```bash
mvn test        # 运行 36 个测试
mvn spring-boot:run
```

## 核心特性

1. **插件机制**：`ServiceLoader` 注册，插件声明 id/名称/版本/适用文件范围/
   可修复能力；加载失败的插件被隔离并记录到具体插件，其余插件正常工作。
2. **目录级配置**：子目录 `.lintrc.json` 继承并覆盖父目录；同级目录互不影响；
   诊断排序稳定可复现，与检查顺序和并发度无关。
3. **行内抑制**：`lint-disable` / `lint-enable` / `lint-disable-line` /
   `lint-disable-next-line`，作用范围确定；未知规则与错误拼写给出可定位提示。
4. **自动修复**：修复前校验文件内容未被用户修改；冲突修复按确定策略裁决；
   原子写入不留半写状态；修复后重新检查确认问题消除。
5. **增量检查**：缓存键覆盖文件内容、有效配置、规则集（id/版本）与引擎版本；
   配置或规则集变化自动失效；LRU 有界淘汰，长期运行不无限增长。
6. **并发与取消**：每文件独立调度与超时；取消后已完成结果保留、未完成标记
   CANCELLED；重查与全量检查结果一致；无半写状态。
